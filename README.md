 Cuestionario Interactivo: Transferencia de Calor IIUna aplicación web interactiva de una sola página (SPA) diseñada para estudiantes de Ingeniería de la Universidad de América. Este simulador sirve como herramienta de estudio y autoevaluación para los conceptos avanzados de diseño térmico y análisis de intercambiadores de calor.✨ Características PrincipalesInterfaz de Usuario Moderna: Diseño visual atractivo utilizando el efecto Glassmorphism (cristal esmerilado) sobre un fondo con gradiente térmico animado.Aleatoriedad Total: Implementa el algoritmo de Fisher-Yates para garantizar que tanto el orden de las 20 preguntas como el orden de las 4 opciones de respuesta sean diferentes en cada intento, evitando la memorización por posición.Fórmulas Matemáticas Nativas: Integración con KaTeX para renderizar ecuaciones termodinámicas y fracciones complejas (como LMTD y NTU) con calidad de libro de texto.Retroalimentación en Tiempo Real: Validación inmediata de las respuestas seleccionadas, mostrando colores intuitivos (verde para aciertos, rojo para errores) y bloqueando las demás opciones.Diseño Responsivo: Adaptable completamente a dispositivos móviles, tablets y computadoras de escritorio gracias a Tailwind CSS.📚 Temario CubiertoEl banco de preguntas incluye 20 ítems rigurosos sobre:Números adimensionales: Reynolds (Re), Prandtl (Pr) y Nusselt (Nu).Tipos de intercambiadores de calor: Configuraciones de flujo (paralelo, contracorriente, cruzado).Método LMTD: Diferencia Media Logarítmica de Temperatura y su factor de corrección ($F$).Método NTU: Número de Unidades de Transferencia, Efectividad ($\varepsilon$) y capacidad térmica mínima ($C_{min}$).Normas TEMA: Clasificación de equipos según su aplicación en la industria.Diseño Estructural: Características, ventajas y componentes de intercambiadores de doble tubo y de coraza y tubos (baffles, pasos múltiples).🚀 Cómo usar este proyectoEste proyecto no requiere de ningún entorno de servidor (Backend) ni dependencias complejas de Node.js. Funciona directamente en el navegador.Clona este repositorio en tu máquina local:git clone https://github.com/tu-usuario/transferencia-calor-quiz.git
Navega a la carpeta del proyecto.Haz doble clic en el archivo portada.html para abrirlo en tu navegador web favorito (Chrome, Edge, Firefox, Safari).¡Haz clic en "Comenzar Cuestionario" y pon a prueba tus conocimientos!🛠️ Tecnologías UtilizadasEstructura y Lógica: HTML5 y Vanilla JavaScript (ES6).Estilos: Tailwind CSS (importado vía CDN para facilitar el despliegue sin compilación).Tipografía: Montserrat de Google Fonts.Renderizado Matemático: KaTeX (importado vía CDN).📝 Cómo agregar nuevas preguntasPuedes expandir el banco de preguntas fácilmente editando el arreglo quizData dentro de la etiqueta <script> del archivo portada.html.// Ejemplo de estructura para una nueva pregunta
